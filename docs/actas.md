### 2. Acuerdos

#### 2.1. Idea elegida

Se acordó desarrollar el proyecto **Acopio de Leche**, una aplicación móvil orientada a digitalizar el registro diario del acopio de leche por productor en las cuencas lecheras de Puno.

La aplicación permitirá registrar la cantidad de leche entregada por cada productor, almacenar información relacionada con la calidad individual de la leche y calcular el pago correspondiente según los datos registrados.

Además, se considera un enfoque **offline-first**, permitiendo utilizar la aplicación sin conexión a Internet y sincronizar posteriormente la información cuando exista conectividad. Esto responde a las condiciones de las zonas rurales donde la señal puede ser limitada o intermitente.

#### 2.2. Ideas descartadas

Durante la selección de la propuesta se analizaron diferentes alternativas:

* **VetCita:** descartada por tener menor relación con el entorno inmediato del equipo.
* **ClubAsistencia:** presenta un alcance válido, pero tiene menor justificación para implementar un funcionamiento offline-first.
* **BibliotecaPréstamos:** presenta un alcance válido, pero tiene menor relación con la problemática identificada y con el requisito de funcionamiento sin conexión.
* **Turismo/Rutas:** descartada porque el inicio de sesión no resulta un requisito natural para el escenario planteado.

Finalmente, se determinó que **Acopio de Leche** presenta una problemática concreta, un alcance realista y una mejor justificación para desarrollar una aplicación móvil con funcionamiento offline-first.
